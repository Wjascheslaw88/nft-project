NFT Project (Frontend)

Клиентская часть SPA-приложения для просмотра и создания NFT-карточек. Взаимодействует с REST API и поддерживает обновления в реальном времени через WebSocket.

## 🛠 Технологии

- **React 18** — библиотека для интерфейсов
- **Redux Toolkit** — управление состоянием
- **React Router v6** — маршрутизация
- **Axios** — HTTP-запросы
- **Material-UI (MUI), Ant Design** — компоненты интерфейса
- **JavaScript, HTML5, CSS3** — основа

## 🚀 Функциональность

- **Просмотр NFT**: карточки подгружаются с пагинацией.
- **Фильтрация**: сортировка по популярности и новизне.
- **Создание NFT**: форма с валидацией для добавления новых карточек.
- **Детальная страница**: просмотр отдельной карточки.
- **Адаптивность**: корректное отображение на разных устройствах.
