# NFT Project (Frontend)

Клиентская часть SPA-приложения для просмотра и создания NFT-карточек. Взаимодействует с REST API.

## 🛠 Технологии

- React 18
- Redux Toolkit
- React Router v6
- Axios
- Material-UI (MUI), Ant Design
- JavaScript, HTML5, CSS3

## 🚀 Функциональность

- Просмотр NFT с пагинацией
- Фильтрация по популярности и новизне
- Создание NFT через форму с валидацией
- Детальная страница карточки
- Адаптивный дизайн

## 📦 Установка и запуск

```bash
git clone https://github.com/Wjascheslaw88/nft-project.git
cd nft-project
npm install
npm start
Приложение будет доступно по адресу: http://localhost:3000

Важно: Для полной работы требуется запущенный бэкенд-сервер. Инструкция в репозитории backend-nft-project.
